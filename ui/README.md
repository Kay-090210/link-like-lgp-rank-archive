# UI模块重构说明

## 模块化重构概述

原始的`gui.py`文件包含1193行代码，过于庞大，不利于维护。经过模块化重构后，代码被拆分为以下结构：

```
ui/
├── __init__.py                 # UI包初始化
├── main_window.py              # 主窗口类 (415行)
├── components/                 # UI组件
│   ├── __init__.py
│   ├── header_widget.py        # 头部组件 (135行)
│   ├── control_card.py         # 控制卡片组件 (180行)  
│   ├── button_group.py         # 按钮组组件 (43行)
│   └── log_widget.py           # 日志组件 (75行)
├── utils/                      # 工具类
│   ├── __init__.py
│   ├── image_loader.py         # 图片加载器 (115行)
│   ├── gui_log_handler.py      # GUI日志处理器 (22行)
│   └── style_manager.py        # 样式管理器 (74行)
└── workers/                    # 后台工作线程
    ├── __init__.py
    └── logger_thread.py        # 日志线程 (232行)
```

## 重构优势

### 1. 代码组织更清晰
- 每个模块职责单一，功能明确
- 便于理解和维护
- 易于单独测试

### 2. 复用性提高
- UI组件可以在其他项目中复用
- 工具类独立，便于扩展

### 3. 可维护性增强
- 修改某个功能只需要关注对应模块
- 减少代码耦合
- 便于团队协作开发

### 4. 扩展性更好
- 新增功能只需要添加对应组件
- 现有代码无需大幅修改

## 文件说明

### 主要组件

- **HeaderWidget**: 应用头部，包含标题、LGP图片和时间信息
- **ControlCard**: 控制面板，包含客户端版本输入和战斗类型选择
- **ButtonGroup**: 按钮组，包含开始按钮
- **LogWidget**: 日志显示组件

### 工具类

- **ImageLoader**: 异步图片加载器，支持重试机制
- **StyleManager**: 统一样式管理，便于主题切换
- **GuiLogHandler**: 自定义日志处理器

### 后台线程

- **LoggerThread**: 数据获取任务的后台线程

## 使用方式

### 启动应用
```bash
python main.py
```

### 开发时运行
```bash
python -m ui.main_window
```
