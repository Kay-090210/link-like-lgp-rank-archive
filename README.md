# Link-Like LGP Rank Archive

This project contains scripts and a small GUI for fetching ranking and profile
information from the Link-Like Lovelive game. Data can be collected and exported
as Excel files.

## Features
- Retrieve grand prix and season grade rankings.
- Fetch player profile and fan level data.
- Provide a PyQt5 GUI for common actions.

## Requirements
See `requirements.txt` for the list of Python packages.

## Usage
1. Install dependencies: `pip install -r requirements.txt`.
2. Configure `account.json` with your login information.
3. Run scripts such as `multicatch.py` or use `gui.py` for a graphical
   interface.
